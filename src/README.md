### Features:

Number Guessing Game
This is a simple number guessing game where the user has to guess a randomly generated number within a given range (e.g., 1 to 100).

Features:
Random number generation.

User input for guesses.

Feedback on whether the guess is too high, too low, or correct.

Difficulty levels (1-10, 1-100, 1-1000).

How to Use:
Run the program in your terminal or IDE.

The program will ask you to choose a difficulty level.

After choosing the level, the program will generate a random number.

Guess the number based on the feedback provided after each attempt (too high, too low, or correct).
